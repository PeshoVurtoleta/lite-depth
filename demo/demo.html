scene 02 - the whole pitch

proven by lite-gc-profiler

Every node dirty every frame -- worst case for transform + project + radix sort + paint. The main-thread frame body allocates zero regardless of count. Toggle off-thread transform to move the transform pass onto a Worker via lite-arena's detach/rebind transferable round-trip -- the main thread's transform reading drops to ~0 (one postMessage replaces the loop). The return-leg rebind (re-viewing the transferred-back buffers) is young-gen only -- major GC still 0, but it is not a 0-byte op, so the badge says main-thread frame body, not the whole round trip.

scene 05 - world-normal lighting

rotated + non-uniform parent

nodes non-uniform- faces drawn- live nodes-
The parent has a non-uniform local scale (2.1 x 0.6 x 1.0) and spins; the uniform child inherits its world matrix. Shading follows the world normal (inverse-transpose), not the local quaternion -- the child stays correctly lit. nodesNonUniform counts the parent only; the inherited-non-uniform child is shaded the same way but not tallied.
